# Internal: GET a Basketball-Reference page and return the response body text

Internal: GET a Basketball-Reference page and return the response body
text

## Usage

``` r
.bref_text(path)
```

## Arguments

- path:

  Page path beginning with `/` (e.g.
  `"/leagues/NBA_2024_per_game.html"`).

## Value

The response body as a character string.
