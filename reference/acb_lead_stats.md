# **Get ACB Lead Stats**

Lead statistics of a game (best run, maximum lead, time ahead, lead
changes) per side.

One row per statistic and side (`stat` is `best_score_run`,
`max_difference`, `time_ahead` or `lead_changes`; `side` home or away).
`value` is the display value as sent (a count, or `'mm:ss'` for time
ahead); `bar_progress` is the length of the site's comparison bar.

Endpoint: `GET https://api2.acb.com/api/matchdata/Overview/lead-tracker`

## Usage

``` r
acb_lead_stats(match_id)
```

## Arguments

- match_id:

  (required) ACB match id (integer), one global sequence for every
  competition: legacy ids (seasons up to 2019-20) sit below about 20000
  (12559 = the 2005-06 final); ids from 2020-21 start around 100000
  (105401 = Barca 89-86 Valencia Basket, Liga 2026-27 round 3). A whole
  number; a whole double is accepted.

## Value

A `hoopR_data` tibble, one row per record described above; the columns
are always these, in this order (sportsdataverse-py `acb_lead_stats`):

|  |  |  |
|----|----|----|
| col_name | type | description |
| match_id | integer | ACB match id (one global sequence for every competition; legacy ids are below about 20000 up to 2019-20, ids from 2020-21 start around 100000). Taken from the request when the body does not name the game. |
| stat | character | Statistic: best_score_run, max_difference, time_ahead or lead_changes. |
| side | character | Side the value belongs to: home or away. |
| value | character | Display value as sent: a count, or 'mm:ss' for time_ahead. |
| bar_progress | double | Length of the site's comparison bar (a drawing value, not a statistic). |
| is_highlighted | logical | True for the side whose bar the site highlights as the better value. |

## Details

Source, terms of use, request pacing, seasons, ids, coverage and error
classes of this family: see the notes in
