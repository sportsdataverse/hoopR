# **Get ESPN NBA Athlete Gamelog**

**Get ESPN NBA Athlete Gamelog**

**Get ESPN NBA Athlete Gamelog**

## Usage

``` r
espn_nba_athlete_gamelog(athlete_id, season = most_recent_nba_season(), ...)
```

## Arguments

- athlete_id:

  ESPN athlete identifier (character or numeric).

- season:

  Season year (numeric). Defaults to the most recent NBA season.

- ...:

  Additional arguments; currently unused.

## Value

A single tibble with one row per game. Column names reflect the stat
labels returned by ESPN and will vary by season and player.
