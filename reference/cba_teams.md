# **Get CBA Teams**

The current team list: logo, team id, club name and display name.

Endpoint: `GET https://data-server.cbaleague.com/api/teams/teamList`

## Usage

``` r
cba_teams()
```

## Value

A `hoopR_data` tibble with one row per club. Its columns are listed in
[return_columns](https://hoopR.sportsdataverse.org/reference/return_columns.md)
(`subset(return_columns, fn == "cba_teams")`) and in the searchable
[return
columns](https://hoopR.sportsdataverse.org/articles/return-columns.html)
article.

## Details

Source, terms of use, request pacing, seasons, ids, coverage and error
classes of this family: see the notes in
[`cba_seasons()`](https://hoopR.sportsdataverse.org/reference/cba_seasons.md).

## See also

[family_cba](https://hoopR.sportsdataverse.org/reference/family_cba.md)
lists every function in this family.
