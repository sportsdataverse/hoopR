# **Get ESPN NBA Venues**

**Get ESPN NBA Venues**

**Get ESPN NBA Venues**

## Usage

``` r
espn_nba_venues(...)
```

## Arguments

- ...:

  Additional arguments; currently unused but retained for forward
  compatibility. Proxy configuration should use
  `options(hoopR.proxy = ...)` – see
  [`?hoopR`](https://hoopR.sportsdataverse.org/reference/hoopR-package.md)
  for details.

## Value

A single `hoopR_data` tibble with one row per venue.

|               |           |                          |
|---------------|-----------|--------------------------|
| col_name      | types     | description              |
| venue_id      | character | Unique venue identifier. |
| name          | character | Display name.            |
| full_name     | character | Player's full name.      |
| address_city  | character |                          |
| address_state | character |                          |
| capacity      | integer   |                          |
| indoor        | logical   |                          |
| grass         | logical   |                          |
| images_url    | character |                          |
