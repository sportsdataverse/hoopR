# Internal: GET a sports-reference.com/cbb page and return the body text

Internal: GET a sports-reference.com/cbb page and return the body text

## Usage

``` r
.srcbb_text(path)
```

## Arguments

- path:

  Page path beginning with `/` (e.g.
  `"/cbb/seasons/2024-school-stats.html"`).

## Value

The response body as a character string.
