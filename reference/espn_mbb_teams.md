# **Get ESPN men's college basketball team names and IDs**

**Get ESPN men's college basketball team names and IDs**

**Get ESPN NBA team names and IDs**

## Usage

``` r
espn_mbb_teams(year = most_recent_mbb_season())

espn_nba_teams()
```

## Arguments

- year:

  Either numeric or character (YYYY)
